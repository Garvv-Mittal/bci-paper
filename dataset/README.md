# Dataset — SEED

**Official Page:** [https://bcmi.sjtu.edu.cn/home/seed/](https://bcmi.sjtu.edu.cn/home/seed/)

---

## What is it?

SEED is an EEG dataset where 15 people watched emotional film clips while their brain signals were recorded. The goal is to build a model that can recognize emotions (positive, neutral, negative) from EEG signals.

---

## Quick Facts

| | |
|-|-|
| **Subjects** | 15 people (7M, 8F) |
| **Emotions** | Positive, Neutral, Negative |
| **Stimuli** | 15 film clips (~4 min each) |
| **Sessions** | 3 per person (1 week apart) |
| **EEG Channels** | 62 |

---

## How to Access

1. Go to [https://bcmi.sjtu.edu.cn/home/seed/](https://bcmi.sjtu.edu.cn/home/seed/)
2. Register and request access
3. Download the preprocessed EEG files

> ⚠️ Do **not** upload dataset files to this repo — they are too large.

---

## Label Convention

| Label | Emotion |
|-------|---------|
| `1` | Positive |
| `0` | Neutral |
| `-1` | Negative |
