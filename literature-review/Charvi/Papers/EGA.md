# EGA

OBJECTIVE-

This paper aimed to improve Weakly Supervised Object Localization (WSOL). In simple words, the model has to find the location of an object in an image without using detailed bounding box labels during training.

The problem with many existing WSOL methods is that they focus only on the most important part of an object. Because of this, complete object localization becomes difficult.

To solve this problem, the researchers proposed EGA . The aim was to make the network learn more object features so that it could identify the whole object instead of only a small region.

METHODOLOGY-

1. EGA combines adversarial learning and entropy minimization to improve object localization.
2. First, adversarial images are generated by adding very small changes to the original image. These changes are almost invisible to humans but force the CNN to look at more object features.
3. Because of this, the network does not depend only on one important region and starts learning object edges, boundaries and other useful information as well.
4. The researchers then applied entropy minimization on the generated Class Activation Maps.
5. Entropy basically represents uncertainty. By reducing entropy, the network becomes more confident and activates more pixels belonging to the object.
6. This helps the model cover a larger area of the object instead of highlighting only a small part.
7. Finally, adversarial loss and entropy loss were combined into a single loss function which helped the network learn better object representations.

RESULTS-

1. The researchers found that EGA performed better than many existing WSOL methods on datasets such as CUB-200-2011, ILSVRC and OpenImages.
2. The model was able to activate more object features and localize a larger portion of the object.
3. When used with the VGG backbone, EGA achieved better classification and localization accuracy compared to previous state-of-the-art methods.
4. The experiments also showed that adversarial learning played an important role in improving localization performance.
5. When entropy minimization was added, the results improved even more which showed that both components were useful.
6. The model generated tighter bounding boxes and was able to identify objects more completely than traditional CAM based approaches.

this paper proposes EGA for weakly supervised object localization.

the main idea of the paper is to make the network look at different parts of an object instead of focusing on only one highly important region.

by using adversarial learning and entropy minimization, the model learns more complete object features and improves localization accuracy.

the method is simple because it does not require detailed bounding box annotations during training and also does not make the network architecture much more complex.
